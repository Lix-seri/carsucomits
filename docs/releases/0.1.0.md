# 0.1.0 — baseline

**Date:** 2026-09-25 (recorded, not released)

This is the state of `main` at commit `ad341f1`, before the audit and restructure began. It exists so that later changelog entries have a reference point; nothing here was changed for it.

**What 0.1.0 does:**
- CSU-email registration and login.
- Posting commissions; browse and search.
- Applications, with accept, decline and withdraw.
- Deliverable uploads with review.
- Mandatory rating on completion, and two-way ratings.
- Messaging, notifications, bookmarks and user reports.
- An admin panel for moderation, reports, listings and logs.
- Admin TOTP MFA.

**Known problems at 0.1.0:** see `docs/ARCHITECTURE.md` at `7485cdf` (the Phase 1 write-up), and the Phase 2 audit in `claude/audits/`.
